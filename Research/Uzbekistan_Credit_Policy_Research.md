## 1. Введение

### Цель исследования

Данное исследование анализирует **кредитную политику Республики Узбекистан** и её
влияние на экономический рост страны. Исследование рассматривает как **позитивные**
эффекты (стимулирование роста, развитие бизнеса, инфраструктурные проекты), так
и **негативные** последствия (инфляция, рост долговой нагрузки, риски финансовой
нестабильности).

### Предмет исследования

**Кредитная политика** — совокупность мер денежно-кредитного регулирования,
осуществляемых Центральным банком Узбекистана (ЦБ РУз) и правительством,
включающих:

- Процентную ставку (ставку рефинансирования)
- Нормативы обязательных резервов
- Параметры кредитования экономики
- Государственные программы льготного кредитования
- Регулирование банковского сектора

### Методология

Исследование основано на анализе:
- Денежно-кредитной политики ЦБ РУз
- Макроэкономических показателей Узбекистана
- Структуры и состояния банковского сектора
- Международных сравнений (страны СНГ, Центральной Азии)
- Макроэкономической теории (кредитный канал монетарной передачи)

> ⚠️ **Важно:** Данные основаны на информации, доступной до момента подготовки
> исследования. Текущие показатели могут отличаться — рекомендуется сверка с
> актуальными данными ЦБ РУз (cbu.uz) и Госкомстата Узбекистана.

## 3. Центральный банк Узбекистана и денежно-кредитная политика

### Центральный банк Республики Узбекистан (ЦБ РУз)

**ЦБ РУз** — главный регулятор денежно-кредитной политики, основанный в 1991 году.

### Мандат ЦБ РУз

| Цель | Описание |
|------|----------|
| **Ценовая стабильность** | Поддержание инфляции на целевом уровне (5% к среднесрочной перспективе) |
| **Стабильность финансовой системы** | Надёжность банков, защита вкладчиков |
| **Поддержка экономического роста** | Создание условий для устойчивого роста (вторичная цель) |

### Денежно-кредитная политика: эволюция

```
До 2017: Административная ДКП
├── Фиксированный валютный курс
├── Множественность курсов
├── Административное распределение кредитов
├── Высокая инфляция (15-20%)
└── Ограниченная роль процентной ставки
         │
         ▼
2017-2020: Переходный период
├── Валютная либерализация (сентябрь 2017)
├── Переход к инфляционному таргетированию (постепенный)
├── Повышение роли ставки рефинансирования
├── Снижение инфляции с 17.5% до ~11%
└── Либерализация кредитных ставок
         │
         ▼
2021-2024: Инфляционное таргетирование
├── Ставка ЦБ как основной инструмент
├── Цель по инфляции: 5% (среднесрочно)
├── Ориентиры денежной массы
├── Коридор ликвидности
└── Улучшение прозрачности и коммуникации
```

## 4. Инструменты кредитной политики

### 4.1. Ставка рефинансирования

Основной инструмент. ЦБ РУз устанавливает ставку, по которой коммерческие банки
могут получать ликвидность от ЦБ. Это влияет на:

- Стоимость межбанковских кредитов
- Ставки по депозитам и кредитам для клиентов
- Уровень экономической активности

```python
# Иллюстрация: влияние ставки ЦБ на кредиты
ставка_цб = 0.14  # 14%
маржа_банка = 0.05  # 5% маржа банка
риск_премия = 0.03  # 3% премия за риск

ставка_кредита = ставка_цб + маржа_банка + риск_премия
# = 22% — реальная ставка по кредитам в экономике

# При снижении ставки ЦБ до 10%:
ставка_цб_new = 0.10
ставка_кредита_new = ставка_цб_new + маржа_банка + риск_премия
# = 18% — кредиты становятся дешевле → рост кредитования
```

### 4.2. Нормативы обязательных резервов

ЦБ РУз устанавливает требования к резервированию средств банков:

| Тип обязательств | Норматив резерва (%) |
|------------------|---------------------|
| Депозиты до востребования | ~10-15% |
| Срочные депозиты (до 1 года) | ~5-10% |
| Срочные депозиты (более 1 года) | ~0-5% |
| Депозиты в иностранной валюте | ~15-20% |

> Более высокие резервы по валютным депозитам — инструмент **дедолларизации**:
  делает валютные депозиты менее привлекательными для банков.

### 4.3. Операции на открытом рынке

ЦБ РУз проводит операции с государственными ценными бумагами для управления
ликвидностью банковского сектора:

- **Репо-операции** — предоставление ликвидности банкам под залог ценных бумаг
- **Депозитные операции** — изъятие избыточной ликвидности
- **Валютные интервенции** — управление курсом сума

### 4.4. Макропруденциальные нормативы

| Норматив | Описание | Цель |
|----------|----------|------|
| **Норматив достаточности капитала (Н1)** | ≥10-12% от активов, взвешенных по риску | Финансовая устойчивость банков |
| **Лимит на одного заёмщика** | ≤25% от капитала банка | Диверсификация рисков |
| **Норматив ликвидности** | ≥30% (текущая ликвидность) | Способность отвечать по обязательствам |
| **Лимит валютной позиции** | Ограничение открытой валютной позиции | Управление валютным риском |
| **Коэффициент покрытия NPL** | Резервы на возможные потери | Защита от невозвратов |

### 4.5. Прямые ограничения и административные меры

В определённые периоды ЦБ РУз использовал административные меры:
- Лимиты на рост кредитования отдельных секторов
- Ограничения на потребительское кредитование
- Требования к кредитованию приоритетных отраслей

## 6. Кредитная экспансия и экономический рост

### Теоретическая основа: кредитный канал

Кредитная экспансия (рост объёма кредитов в экономике) влияет на экономический
рост через несколько каналов:

```
Рост кредитования
        │
        ├──► Инвестиции в бизнес → Рост производственных мощностей → Рост ВВП
        │
        ├──► Потребительские кредиты → Рост потребления → Рост спроса → Рост ВВП
        │
        ├──► Кредиты МСП → Рост занятости и инноваций → Рост ВВП
        │
        ├──► Инфраструктурные проекты → Рост производительности → Рост ВВП
        │
        └──► Ипотека → Рост строительства → Рост смежных отраслей → Рост ВВП
```

### Эмпирические данные: Узбекистан

| Период | Рост кредитов (%) | Рост ВВП (%) | Связь |
|--------|-------------------|-------------|-------|
| 2018-2019 | ~20-25% | ~5.3-5.6% | Кредитный рост опережает ВВП |
| 2020 (COVID) | ~15% | ~1.6% | Падение роста при замедлении кредитования |
| 2021 | ~20% | ~7.4% | Кредитная экспансия → восстановление роста |
| 2022 | ~20% | ~5.4% | Продолжение роста, но инфляционное давление |
| 2023 | ~15% | ~5.0% | Замедление кредитования → стабилизация |

### Анализ: корреляция кредит → рост

```python
# Иллюстративная модель: вклад кредитного роста в ВВП
credit_growth = [25, 15, 20, 20, 15]  # % рост кредитов (2019-2023)
gdp_growth = [5.6, 1.6, 7.4, 5.4, 5.0]  # % рост ВВП

# Корреляция Пирсона
import statistics
mean_c = statistics.mean(credit_growth)
mean_g = statistics.mean(gdp_growth)

covariance = sum((c - mean_c) * (g - mean_g) 
                 for c, g in zip(credit_growth, gdp_growth)) / len(credit_growth)
std_c = statistics.stdev(credit_growth)
std_g = statistics.stdev(gdp_growth)

correlation = covariance / (std_c * std_g)
# Ожидаемая корреляция: ~0.6-0.8 (положительная, но не идеальная)
# Вывод: кредитный рост положительно связан с экономическим ростом,
# но не является единственным фактором
```

> **Вывод:** В Узбекистане наблюдается **положительная корреляция** между ростом
> кредитования и экономическим ростом. Однако кредитная экспансия опережает рост
> ВВП, что создаёт **инфляционные риски** (подробнее в разделе 9).

### Мультипликатор кредита

Эффект мультипликатора: каждый 1 сум кредитов генерирует >1 сум экономической
активности (через оборачиваемость денег):

```
Банк выдаёт кредит 1000 сум
    │
    ▼
Заёмщик тратит (зарплаты, закупки, инвестиции)
    │
    ▼
Получатели тратят (потребление, сбережения)
    │
    ▼
Часть возвращается в банк как депозиты → новые кредиты
    │
    ▼
Мультипликативный эффект: ~1000 → 1500-2000 сум экономической активности
```

> В Узбекистане мультипликатор может быть **ниже** теоретического из-за:
> - Высокой доли наличных расчётов (хотя снижается)
> - Долларизации (часть сбережений в валюте, вне банковской системы)
> - Высоких резервных требований

## 8. Негативное влияние и риски

### 8.1. Инфляционное давление

**Главный риск кредитной экспансии** — рост инфляции.

```
Рост кредитования → Рост спроса (потребление + инвестиции)
                          │
                          ▼
              ┐
              │  Если предложение не успевает за спросом:
              │  ├── Рост цен на товары → Инфляция
              │  ├── Рост цен на недвижимость → Инфляция активов
              │  └── Рост зарплат → Инфляция издержек
              ┘
                          │
                          ▼
              ┌──────────────────────┐
              │  Инфляция > целевой  │
              │  уровень (5%)        │
              └──────────────────────┘
```

**Эмпирические данные Узбекистана:**

| Период | Рост кредитов (%) | Инфляция (%) | Связь |
|--------|-------------------|-------------|-------|
| 2018 | ~20% | 17.5% | Высокая инфляция при быстром кредитном росте |
| 2020 | ~15% | 11.1% | Замедление кредитования → снижение инфляции |
| 2021 | ~20% | 9.0% | Кредитный рост без существенного роста инфляции |
| 2022 | ~20% | 11.3% | Кредитная экспансия + внешние факторы → рост инфляции |
| 2023 | ~15% | 9.0% | Замедление кредитования → снижение инфляции |

> **Вывод:** Кредитная экспансия в Узбекистане **сопровождается инфляционным
> давлением**. ЦБ вынужден балансировать между стимулированием роста и
> сдерживанием инфляции.

### 8.2. Рост долговой нагрузки

```python
# Иллюстрация: рост долговой нагрузки населения и бизнеса

# Потребительские кредиты: быстрый рост
consumer_loans = {
    2019: 15,   # млрд сум (условные)
    2020: 18,
    2021: 22,
    2022: 28,
    2023: 35
}

# Рост за 4 года: 15 → 35 = 133%
# Рост доходов за тот же период: ~50-60%
# Вывод: долг растёт БЫСТРЕЕ доходов → рост долговой нагрузки

debt_to_income = {
    2019: 0.20,  # долг = 20% годового дохода
    2020: 0.22,
    2021: 0.24,
    2022: 0.27,
    2023: 0.30   # долг = 30% годового дохода
}

# Риск: при росте долговой нагрузки → рост невозвратов (NPL)
# Особенно уязвимы: низкодоходные группы, взявшие потребкредиты
```

**Риски роста долговой нагрузки:**

| Риск | Описание |
|------|----------|
| **Рост невозвратов (NPL)** | Заёмщики не справляются с платежами |
| **Снижение потребления** | Рост платежей по долгам → меньше свободных средств |
| **Финансовый стресс населения** | Психологическое и экономическое давление |
| **Системный риск** | Массовые невозвраты → проблемы банков → финансовый кризис |

### 8.3. Перегрев отдельных секторов

Кредитная экспансия может привести к **перегреву** — избыточному росту цен
в отдельных секторах:

| Сектор | Риск перегрева | Индикатор |
|--------|---------------|-----------|
| **Недвижимость** | Рост цен на жилье при росте ипотеки | Цена/доход ratio |
| **Потребительское кредитование** | Избыточное потребление | Долг/доход ratio |
| **Торговля** | Избыточные запасы, перепроизводство | Кредиты/обороты |
| **Строительство** | Незавершённые проекты при избытке кредитов | Доля незавершёнки |

### 8.4. Риск «плохих» кредитов и госпрограмм

```
Государственные льготные кредиты
        │
        ├──► Плюс: поддержка приоритетных отраслей, МСП, сельского хозяйства
        │
        └──► Минусы:
            ├── Целевое использование не всегда контролируется
            ├── Низкие ставки → моральный риск (безответственное заимствование)
            ├── Невозвраты → потери для госбанков → бюджетные риски
            ├── Искажение рыночных сигналов (нерыночные ставки)
            └── Коррупционные риски при распределении
```

### 8.5. Смещение от сбережений к потреблению

Высокая инфляция и низкие реальные ставки по депозитам стимулируют потребление
вместо сбережений:

```
Реальная ставка по депозиту = Номинальная ставка - Инфляция
                             = 15% - 10% = 5% (положительная, но низкая)
                             = 12% - 12% = 0% (нулевая)
                             = 10% - 14% = -4% (отрицательная!)
```

При **отрицательной реальной ставке**:
- Население предпочитает тратить, а не сберегать
- Снижается долгосрочный ресурс банков (срочные депозиты)
- Банки зависят от краткосрочных и валютных ресурсов

## 10. Долларизация и валютная политика

### Проблема долларизации

Узбекистан исторически имеет высокий уровень **дедолларизации** как цель ЦБ.
Население и бизнес сохраняют сбережения в долларах США из-за:
- Истории высокой инфляции и девальвации сума
- Недоверия к национальной валюте
- Инфляционных ожиданий

### Уровень долларизации

| Показатель | 2018 | 2020 | 2022 | 2023 | Тренд |
|------------|------|------|------|------|-------|
| **Доля валютных депозитов (%)** | ~45-50% | ~40% | ~35% | ~30% | ↓ Снижение |
| **Доля валютных кредитов (%)** | ~40-45% | ~35% | ~30% | ~25% | ↓ Снижение |
| **Доля валютных активов банков (%)** | ~40% | ~35% | ~30% | ~25% | ↓ Снижение |

> **Позитивный тренд:** уровень долларизации снижается благодаря реформам ЦБ РУз.

### Меры дедолларизации

| Мера | Описание |
|------|----------|
| **Повышенные резервы по валютным депозитам** | Делает валютные депозиты дороже для банков |
| **Запрет валютных кредитов** | Ограничение валютного кредитования (нерезидентам, некоторые категории) |
| **Обязательная продажа валютной выручки** | Частичная продажа экспортёрами |
| **Развитие рынка сумовых инструментов** | Государственные ценные бумаги в сумах |
| **Курсовая стабильность** | Предсказуемость курса снижает спрос на валюту |

### Влияние долларизации на кредитную политику

```
Высокая долларизация
        │
        ├──► Ослабление кредитного канала ДКП
        │    (изменение ставки ЦБ меньше влияет на валютные кредиты)
        │
        ├──► Валютный риск для заёмщиков
        │    (девальвация сума → рост долга в сумовом эквиваленте)
        │
        ├──► Риск системного кризиса
        │    (массовая девальвация → массовые невозвраты валютных кредитов)
        │
        └──► Ограничение эффективности монетарной политики
             (ЦБ меньше контролирует денежную массу)
```

### Риски NPL для экономики

| Риск | Описание |
|------|----------|
| **Убытки банков** | Снижение прибыли, необходимость резервирования |
| **Сокращение кредитования** | Банки становятся осторожнее → меньше кредитов → замедление роста |
| **Системный риск** | Массовые невозвраты → угроза финансовой стабильности |
| **Бюджетные потери** | Невозвраты по госпрограммам → нагрузка на бюджет |
| **Социальные последствия** | Финансовый стресс заёмщиков, банкротства |

### Меры по снижению NPL

1. **Ужесточение оценки заёмщиков** — кредитный скоринг, проверка кредитной истории
2. **Развитие кредитных бюро** — централизованная информация о заёмщиках
3. **Реструктуризация проблемных кредитов** — программы для заёмщиков в трудной ситуации
4. **Усиление надзора ЦБ** — мониторинг качества портфелей банков
5. **Резервирование** — адекватные резервы на возможные потери

## 15. Ключевые вызовы

### 15.1. Снижение инфляции до целевого уровня

**Проблема:** Инфляция стабильно выше цели (5%), что подрывает доверие к монетарной политике.

**Факторы:**
- Высокий рост кредитования опережает рост производства
- Инфляционные ожидания населения остаются высокими
- Административные и продовольственные факторы
- Влияние курса сума

### 15.2. Доминирование государственных банков

**Проблема:** ~60-70% активов в госбанках → ограничение конкуренции, политическое
влияние на кредитование, нерыночные ставки.

**Риски:**
- Снижение эффективности распределения капитала
- Политическое кредитование (не по экономическим критериям)
- Риск невозвратов по политическим кредитам
- Ограничение развития частных банков

### 15.3. Рост долговой нагрузки населения

**Проблема:** Быстрый рост потребительских кредитов (~25-30% в год) опережает
рост доходов (~15-20%), что повышает риски невозвратов.

**Индикаторы:**
- Долг/доход ratio растёт
- Доля потребкредитов в портфелях банков растёт
- Риск массовых невозвратов при экономическом шоке

### 15.4. Дедолларизация

**Проблема:** Несмотря на снижение, ~30% депозитов и ~25% кредитов в валюте.

**Риски:**
- Ослабление монетарной передачи
- Валютный риск для заёмщиков
- Уязвимость к девальвации

### 15.5. Качество кредитного портфеля

**Проблема:** NPL на уровне 3-5%, с риском роста при шоках.

**Факторы риска:**
- Государственные льготные кредиты (риск невозвратов)
- Быстрый рост потребкредитования
- Недостаточный кредитный скоринг

### 15.6. Зависимость от внешних факторов

**Проблема:** Экономика чувствительна к:
- Ценам на золото и другие экспортные товары
- Глобальной инфляции
- Курсу сума к доллару и рублю
- Санкционной геополитике (косвенное влияние)

### 16.5. Баланс: рост vs стабильность

```
                Рост кредитования
                     │
         Слишком мало│     Слишком много
                     │
    ─────────────────┼─────────────────
                     │
    Замедление       │    Инфляция, риски,
    роста,           │    пузыри, NPL,
    недофинансиро-   │    финансовая
    вание            │    нестабильность
                     │
    ─────────────────┼─────────────────
                     │
              ОПТИМАЛЬНЫЙ
              УРОВЕНЬ
              │
              ▼
    Кредиты растут вровень
    или чуть быстрее ВВП,
    при контролируемой
    инфляции и низком NPL
```

> **Ключевой вывод:** Оптимальная кредитная политика — это **баланс** между
> стимулированием роста и сдерживанием рисков. Кредиты должны расти **умеренно
> быстрее ВВП** (на 2-4 п.п.), при контроле инфляции и качества портфеля.

## 17. Глоссарий

| Термин | Определение |
|--------|-------------|
| **Кредитная политика** | Совокупность мер по регулированию кредитования экономики |
| **Денежно-кредитная политика (ДКП)** | Политика ЦБ по управлению денежной массой и ставками |
| **Ставка рефинансирования** | Процентная ставка ЦБ, по которой банки получают ликвидность |
| **Инфляционное таргетирование** | Режим ДКП с целевым уровнем инфляции как главной целью |
| **Реальная процентная ставка** | Номинальная ставка минус инфляция |
| **Обязательные резервы** | Часть депозитов, которую банки обязаны держать в ЦБ |
| **NPL (Non-Performing Loans)** | Просроченные/проблемные кредиты |
| **Долларизация** | Использование иностранной валюты в качестве средства сбережения |
| **Дедолларизация** | Политика снижения доли валюты в экономике |
| **Макропруденциальная политика** | Регулирование для обеспечения финансовой стабильности |
| **Финансовая инклюзия** | Доступность финансовых услуг для всего населения |
| **Кредитный мультипликатор** | Эффект расширения денежной массы через кредитование |
| **Монетарная передача** | Механизм влияния ДКП на экономику |
| **Госбанки** | Банки с государственным участием |
| **МСП** | Малый и средний бизнес |
| **Кредитный скоринг** | Оценка кредитоспособности заёмщика |
| **Кредитное бюро** | Организация, собирающая кредитные истории |
| **Коридор ликвидности** | Диапазон ставок ЦБ для управления ликвидностью |
| **Репо** | Операции покупки/продажи ценных бумаг с обратным выкупом |
| **ЦБ РУз** | Центральный банк Республики Узбекистан |
