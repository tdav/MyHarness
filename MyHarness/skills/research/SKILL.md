## Применение

Когда пользователь просит исследовать, обобщить или проанализировать тему:

1. **Определите рамки** — решите, что здесь означает «исследование»: какие файлы/папки входят в рамки и каков результат (сводка, отчёт, решение).
2. **Соберите данные** — используйте `search_files` для поиска релевантного содержимого в рабочей папке, затем `file_access` для чтения найденного. Используйте `run_shell` (Get-ChildItem, Select-String) для более широких проверок файловой системы.
3. **Вычислите** — когда нужны подсчёты, статистика или перекрёстные ссылки, пишите Python и запускайте через `execute_code`, а не считайте вручную.
4. **Обобщите** — запишите результат в файл в рабочей папке (например, `research-report.md`) через `file_access`, а также покажите пользователю ключевые выводы прямо в ответе.
5. **Сохраните** — запишите долговременные выводы в файловую память, чтобы следующая сессия могла на них опереться.

## Пример

```
search_files pattern="TODO" path=""
# прочитать найденные файлы, подсчитать по статусам, записать report.md
```
