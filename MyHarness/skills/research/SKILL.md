## Применение

Когда пользователь просит исследовать, обобщить или проанализировать тему:

1. **Определите рамки** — решите, что здесь означает «исследование»: какие файлы/папки входят в рамки и каков результат (сводка, отчёт, решение).
2. **Соберите данные** — используйте `search_files` для поиска релевантного содержимого в рабочей папке, затем `file_access` для чтения найденного. Используйте `run_shell` (Get-ChildItem, Select-String) для более широких проверок файловой системы.
3. **Проверьте по внешним источникам** — всё, чего нет в рабочей папке (версии, даты, цены,
   стандарты, состояние рынка), ищите через `web_search` и читайте через `web_fetch`. Никогда не
   берите такие факты из собственной памяти — она устарела. Рядом с каждым внешним фактом ставьте
   URL источника и дату публикации. Если веб-инструменты недоступны, так и напишите в отчёте и
   укажите, что данные не проверены.
4. **Вычислите** — когда нужны подсчёты, статистика или перекрёстные ссылки, пишите Python и запускайте через `execute_code`, а не считайте вручную.
5. **Обобщите** — запишите результат в файл в рабочей папке (например, `research-report.md`) через `file_access`, а также покажите пользователю ключевые выводы прямо в ответе.
6. **Сохраните** — запишите долговременные выводы в файловую память, чтобы следующая сессия могла на них опереться.

## Пример

```
search_files pattern="TODO" path=""
# прочитать найденные файлы, подсчитать по статусам, записать report.md
```
