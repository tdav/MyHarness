## Применение

Когда задача решается C#-скриптом:

1. **Папка** — убедитесь через `file_access`, что в рабочей папке есть `scripts/`
   (создайте при необходимости). Все скрипты живут только там.
2. **Напишите скрипт** — один `.cs`-файл с top-level statements (без csproj).
   Первая строка — комментарий: назначение и команда запуска. NuGet-пакеты —
   директивой `#:package Имя@Версия` в начале файла.
3. **Запустите** — через `run_shell`: `dotnet run scripts\имя.cs -- <аргументы>`
   (рабочий каталог оболочки — рабочая папка; запуск происходит в дочернем процессе
   и подтверждается пользователем).
4. **Итерация** — при ошибке прочитайте вывод компилятора/исключение, исправьте файл
   через `file_access` (edit), перезапустите. Не отвечайте пользователю, пока скрипт
   не отработал успешно.
5. **Отчёт** — покажите код и фактический вывод; долговременные выводы сохраните
   в файловую память.

## Роли

Для специализации примите соответствующую персону из папки agents рядом с приложением:
`dotnet-scripter` (общие скрипты), `dotnet-analyst` (анализ данных),
`dotnet-automator` (автоматизация файловых операций).

## Примеры в scripts/

- `hello.cs` — минимальный скрипт: аргументы командной строки и вывод.
- `sysinfo.cs` — доступ к BCL: сведения о системе и дисках.
- `todo-report.cs` — обход файлов, поиск TODO, запись Markdown-отчёта.
